float LireTensionADC ( ADC_HandleTypeDef * hadc,
uint32_t canal,
float ratio_pont )
static

Lit une conversion ADC sur le canal donne et la convertit en tension REELLE cote LDO (avant le pont diviseur), a partir du ratio R2/(R1+R2) du pont utilise. Resolution 16 bits (ADC_RESOLUTION_16B, deja configuree sur hadc1/hadc3) : plage brute 0-65535 pour 0-VDDA (3.3V typique).

Paramètres
hadcHandle ADC a utiliser (&hadc1 pour PC0/canal 10, &hadc3 pour PF4/canal 9).
canalCanal ADC a lire (ex : ADC_CANAL_TENSION ou ADC_CANAL_COURANT). RECONFIGURE le canal actif de hadc a chaque appel (HAL_ADC_ConfigChannel) : necessaire des qu'un meme ADC (ex : hadc3) doit lire plusieurs canaux differents selon le contexte (ex : canal 1 pour GET_CURRENT_2, canal 9 pour la mesure de courant LDO).
ratio_pontR2 / (R1 + R2) du pont diviseur utilise (0.5f pour le pont partage R1=R2=10k de ce montage).
Valeurs retournées
floatTension reelle en volts, cote sortie du LDO (deja divisee par ratio_pont pour "annuler" l'effet du pont). Retourne -1.0f en cas d'echec de conversion (timeout) ou de configuration du canal.
Exemple d'utilisation
float v = LireTensionADC(&hadc1, ADC_CANAL_TENSION, MUX_RATIO_PONT);

◆ h_GET_ADC_BRUT()

void h_GET_ADC_BRUT ( void )
static

Handler de la commande reseau "GET_ADC_BRUT:<numero_adc>:<canal>".

  • lit un canal ADC DIRECTEMENT, sans passer par le multiplexeur (SelectionnerCanalMuxTension/Courant). Utile en phase de test sur breadboard, quand le multiplexeur n'est pas encore cable : on branche l'ADC directement sur la sortie a verifier (ex : un VOUT precis de 0xC4).
    Paramètres
    Aucunparametre C. Lit last_message (deja positionne apres le premier ':' par tc_request()), format "<numero_adc>:<canal>" : numero_adc = 1 (hadc1) ou 3 (hadc3), canal = numero ADC_CHANNEL_x.
    Valeurs retournées
    Aucun(void). Remplit response avec "ADC_BRUT:<tension>V\n" si la lecture reussit, ou "ADC_BRUT:ERREUR_PARAMETRES\n" / "ADC_BRUT:ERREUR\n" sinon. Tension calculee SANS aucun pont diviseur (ratio 1.0f) : c'est la tension reelle au pin ADC, a toi de tenir compte d'un eventuel pont externe manuellement.
    Exemple d'utilisation
    Trame UDP recue : "GET_ADC_BRUT:1:4"
    -> lit hadc1, ADC_CHANNEL_4, repond "ADC_BRUT:1.650V\n"
