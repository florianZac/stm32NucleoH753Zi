void tc_request (void)
 Analyseur (parser) principal des trames recues par UDP. Extrait le premier token de la trame (avant le premier ":"), puis tente de le faire correspondre, dans l'ordre : 1) aux prefixes indexes par LDO (SET_EN_LDO_, RST_EN_LDO_, SET_BL_LDO_, RST_BL_LDO_, GET_STATUS_LDO_) via findLdoIndex() ; 2) sinon, a une commande exacte de commandTable[] via findCommandHandler(), dont le handler associe est alors execute. Si aucune correspondance n'est trouvee, la reponse "UNKNOWN" est renvoyee.

void tc_request ( void )

Analyseur (parser) principal des trames recues par UDP. Extrait le premier token de la trame (avant le premier ":"), puis tente de le faire correspondre, dans l'ordre : 1) aux prefixes indexes par LDO (SET_EN_LDO_, RST_EN_LDO_, SET_BL_LDO_, RST_BL_LDO_, GET_STATUS_LDO_) via findLdoIndex() ; 2) sinon, a une commande exacte de commandTable[] via findCommandHandler(), dont le handler associe est alors execute. Si aucune correspondance n'est trouvee, la reponse "UNKNOWN" est renvoyee.

Paramètres
Aucunparametre C. Lit et modifie la variable globale last_message (message brut recu), et ecrit le resultat dans la variable globale response.
Valeurs retournées
Aucun(void).
Exemple d'utilisation
last_message = "SET_VAL_LDO_1PSp:2048";
tc_request(); // -> execute h_SET_VAL_LDO_1PSp(), response="DONE"
