 Ecrit un registre VOLATILE de CONFIGURATION du DAC MCP47FEB28 (adresses memoire 08h/09h/0Ah UNIQUEMENT). Meme garde-fou que EcrireDACVolatile()/LireRegistreConfigDAC() : toute adresse hors de {0x08, 0x09, 0x0A} est refusee, aucune trame emise. ATTENTION : contrairement a EcrireDACVolatile() (une sortie a la fois), ces 3 registres s'appliquent AUX 8 CANAUX DE LA PUCE A LA FOIS (2 bits/canal pour VREF et Power-Down, 1 bit/ canal pour Gain) - voir Registres 4-2/4-3/4-4 du datasheet. static void InitialiserConfigDacsI2C1 (void)
 Force la configuration VOLATILE des MCP47FEB28 de I2C1 a l'etat attendu par tout le reste du firmware : VREF = VDD (5V) sur les 8 canaux, sortie en fonctionnement normal (pas de Power-Down), gain 1x. Relit ensuite les 3 registres et envoie le resultat sur USART1. Pourquoi : le firmware ne configurait JAMAIS ces registres. Chaque puce demarre donc sur les valeurs de son EEPROM, qui peuvent differer d'une puce a l'autre (programmation anterieure, trame parasite, ex : le texte "Bonjour" de la capture bouton USER, envoye a 0xC0/0xC2 avant le correctif). Si l'EEPROM de la puce 0xC2 contient VREF = bande interdite (~1.2V) ou un mode Power-Down, SET_VAL_LDO_1PLp ne peut pas couvrir 0-5V alors que la puce 0xC0 (1PSp/2PSp) fonctionne. Registres 08h/09h/0Ah volatils uniquement : l'EEPROM n'est jamais touchee.

uint16_t VoltageVersCodeDAC ( float tension_desiree,
float tension_reference )
static

Convertit une tension desiree (en volts) en code numerique 12 bits (0-4095) compris par le DAC, selon la formule : code = (tension_desiree / tension_reference) * 4095. Dans la config actuelle du DAC (registre VREF a sa valeur par defaut, VDD utilise comme reference), tension_reference doit etre la tension VDD REELLE mesuree sur le DAC (pas forcement 5V pile - utilise la valeur que tu as mesuree au multimetre pour plus de precision).

Paramètres
tension_desireeTension de sortie voulue, en volts (ex : 5.0f). Ecretee automatiquement entre 0 et tension_reference.
tension_referenceTension de reference reelle du DAC (VDD mesure), en volts.
Valeurs retournées
uint16_tCode 12 bits (0-4095) a passer a EcrireDACVolatile() ou BalayerSortieDAC().
Exemple d'utilisation
// Ecrire 5V sur VOUT0, avec un VDD reellement mesure a 5V :
uint16_t code = VoltageVersCodeDAC(5.0f, 5.0f); // -> 4095
EcrireDACVolatile(&hi2c1, (0x62 << 1), 0x00, code);
// Ecrire 2.5V (moitie de VDD), avec VDD mesure a 4.98V :
uint16_t code2 = VoltageVersCodeDAC(2.5f, 4.98f); // -> ~2056

void h_SET_DAC_GAIN ( void )
static

Exemple d'utilisation
Trame UDP recue : "SET_DAC_GAIN:1:0xC4:0x00"
-> force gain 1x sur les 8 canaux du DAC a 0xC4 sur hi2c1.
