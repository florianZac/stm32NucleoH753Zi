static void InitialiserConfigDacsI2C1 (void)
 Force la configuration VOLATILE des MCP47FEB28 de I2C1 a l'etat attendu par tout le reste du firmware : VREF = VDD (5V) sur les 8 canaux, sortie en fonctionnement normal (pas de Power-Down), gain 1x. Relit ensuite les 3 registres et envoie le resultat sur USART1. Pourquoi : le firmware ne configurait JAMAIS ces registres. Chaque puce demarre donc sur les valeurs de son EEPROM, qui peuvent differer d'une puce a l'autre (programmation anterieure, trame parasite, ex : le texte "Bonjour" de la capture bouton USER, envoye a 0xC0/0xC2 avant le correctif). Si l'EEPROM de la puce 0xC2 contient VREF = bande interdite (~1.2V) ou un mode Power-Down, SET_VAL_LDO_1PLp ne peut pas couvrir 0-5V alors que la puce 0xC0 (1PSp/2PSp) fonctionne. Registres 08h/09h/0Ah volatils uniquement : l'EEPROM n'est jamais touchee.
