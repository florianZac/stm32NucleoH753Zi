void h_SET_DELTA_DVDD_AVDD ( void )
static

Handler de la commande reseau "SET_DELTA_DVDD_AVDD". Met a jour le delai de sequencement delta_dvdd_avdd (en ms) a partir de la valeur recue apres le "'" dans la trame.

Paramètres
Aucunparametre C. La valeur est lue dans la variable globale last_message, au format attendu "SET_DELTA_DVDD_AVDD:<valeur_ms>".
Valeurs retournées
Aucun(void). Effet de bord : delta_dvdd_avdd mis a jour.
Exemple d'utilisation
Trame UDP recue : "SET_DELTA_DVDD_AVDD:750" -> delta_dvdd_avdd = 750;
