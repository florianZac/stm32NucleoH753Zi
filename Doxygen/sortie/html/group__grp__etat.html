◆ buildStatusResponse()

void buildStatusResponse ( int idx)
static

Construit la chaine de statut complete d'une LDO et la place dans la variable globale response, pour repondre a une commande "GET_STATUS_LDO_<nom>". Cas particulier : pour les LDO de type "PL_p" (ex: 1PLp, 2PLp, 3PLp), qui n'ont pas de mesure de courant, le champ Current affiche "NONE" au lieu d'une valeur numerique.

ATTENTION a l'interpretation du champ OC : ce n'est PAS un defaut absolu, mais la sortie d'un comparateur analogique dont le SEUIL de declenchement est fixe par la valeur "Current" elle-meme (via un pont diviseur pilote par le DAC courant, voir le commentaire au-dessus de la declaration des struct LDO_x_PS_p/n plus haut dans ce fichier). Un meme courant reel peut donc donner OC=0 ou OC=1 selon la valeur de Current configuree au moment de la lecture - toujours lire les deux champs ensemble, jamais OC isolement.

Paramètres
idxIndice de la LDO dans ldoConfig[] (0..17), typiquement obtenu via findLdoIndex().
Valeurs retournées
Aucun(void). Ecrit la chaine formatee dans response, ex : "LDO_1PSp:: En:1, Bl:0, PG:1, OC:0, Voltage:2047, Current:2047, delta_ON:0, delta_OFF:0".
Exemple d'utilisation
int idx = findLdoIndex("1PSp");
if (idx != -1) buildStatusResponse(idx);

◆ LDO_RelacherBleeder()

uint8_t LDO_RelacherBleeder ( int idx)
static

Desactive le bleeder d'une LDO (RST_BL_LDO_<nom>, RST_BL_LDO_ALL, SET_BL_TAB avec 0). C'est aussi la procedure de rearmement apres un declenchement OC : le defaut memorise est efface si la broche OC est revenue au repos ; sinon le bleeder reste actif et le defaut aussi. L'EN reste a 0 dans tous les cas : l'operateur le reactive ensuite.

Paramètres
idxIndex de la LDO (0-17).
Valeurs retournées
0= bleeder desactive, aucun defaut ; 1 = bleeder desactive ET defaut OC efface (rearme) ; 2 = refus : la broche OC signale encore une surintensite.
Exemple d'utilisation
if (LDO_RelacherBleeder(findLdoIndex("2PSp")) == 2U) { refuser(); }
