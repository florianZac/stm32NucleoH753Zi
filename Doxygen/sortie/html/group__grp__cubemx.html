◆ main()

int main ( void )

The application entry point.

Valeurs retournées
int
Role dans le projet
Point d'entree. Configure la MPU, active les caches, initialise le HAL, attend 1 s, configure les horloges, debloque les deux bus I2C (I2C_BusRecovery() sur PB8/PB9 et PB10/PB11), initialise les GPIO et peripheriques CubeMX, puis LDO_GPIO_Init() (broches des LDO depuis ldoConfig[]). Cree ensuite la tache lwipTask (StartLwipTask()) et demarre FreeRTOS : la boucle while(1) n'est jamais atteinte.
Exemple d'utilisation
// appele par le code de demarrage (startup_stm32h753zitx.s), ne pas appeler directement

Définition à la ligne 1824 du fichier main.c.

void HAL_TIM_PeriodElapsedCallback ( TIM_HandleTypeDef * htim)

Period elapsed callback in non blocking mode.

Note
This function is called when TIM6 interrupt took place, inside HAL_TIM_IRQHandler(). It makes a direct call to HAL_IncTick() to increment a global variable "uwTick" used as application time base.
Paramètres
htim: TIM handle
Valeurs retournées
None
Role dans le projet
Base de temps du HAL sur TIM6 (SysTick reserve a FreeRTOS) : incremente uwTick, donc HAL_GetTick() et HAL_Delay().
