static void MX_OC_EXTI_Init (void)
 Met en interruption la broche OC de chaque LDO declaree avec oc.interruption = 1 dans ldoConfig[], sur le front qui correspond a l'apparition d'une surintensite (montant si niveau_defaut = SET). Refuse (ligne UART "OC_EXTI:<nom>:REFUS_LIGNE_n") une broche dont la ligne EXTI est deja prise (bouton, ou autre LDO de meme numero de broche sur un autre port) : la LDO reste alors surveillee par la boucle seule. Aucune API FreeRTOS n'est appelee dans l'IT : la priorite 2 peut etre plus haute que configMAX_SYSCALL_INTERRUPT_PRIORITY.
